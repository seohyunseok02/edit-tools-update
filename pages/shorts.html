쇼츠 자동 편집기

완성된 미드폼 프로젝트에서 구간을 골라, 쇼츠 디자인 프로젝트의 자막·효과로 쇼츠를 만들어 넣습니다. 프로젝트 파일은 이 브라우저 안에서만 처리됩니다.

1프로젝트 넣기 두 파일을 끌어다 놓으세요. 원본은 바뀌지 않습니다.

미드폼 프로젝트완성된 가로 영상 .prproj
쇼츠 디자인 프로젝트자막·효과음 견본이 든 세로 .prproj

2읽은 내용 확인 자동으로 찾은 값입니다. 틀린 곳만 고치세요.

3구간 고르기 말자막 대본을 읽고 쇼츠가 될 만한 구간을 찾습니다.

GPT 연결 (OpenAI API)

키는 platform.openai.com 의 API keys 에서 만듭니다. ChatGPT 구독과는 별개로 쓴 만큼 요금이 나옵니다. 키는 이 페이지에서 OpenAI로만 보내집니다.

AI에게 물어보기

  1. 요청문 복사를 누릅니다.
  2. ChatGPT를 열어 새 대화에 붙여넣고 보냅니다. ChatGPT 열기
  3. ChatGPT가 준 답 전체를 복사해 아래 칸에 붙여넣고 답 적용을 누릅니다.
복사 버튼이 안 될 때: 요청문을 직접 선택해 복사하기

4쇼츠 만들기 고른 구간마다 문구를 확인한 뒤 프로젝트 파일로 받습니다.
