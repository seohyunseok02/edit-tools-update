효과자막 자동 편집기

컷편집과 말자막까지 끝난 미드폼 프로젝트에, 업체의 디자인 템플릿과 그 업체가 써 온 방식대로 효과자막과 효과음을 넣습니다. 프로젝트 파일은 이 브라우저 안에서만 처리됩니다.

1업체 업체마다 템플릿과 스타일을 한 번 등록해 두면 다음부터는 고르기만 하면 됩니다.

미드폼 디자인 템플릿이 업체의 템플릿 .prproj 를 넣으세요
스타일 배우기 (선택)이 업체의 완성 프로젝트 .prproj 를 2~3개 넣으세요

2컷편집본 넣기 컷편집 · 빈 구간 제거 · 기본 말자막이 끝난 미드폼 프로젝트. 원본은 바뀌지 않습니다.

미드폼 프로젝트.prproj 를 끌어다 놓으세요

3효과자막 제안 말자막 대본을 읽고 넣을 자리와 디자인, 문구를 제안합니다. 고치거나 빼세요.

GPT 연결 (OpenAI API)

키는 platform.openai.com 의 API keys 에서 만듭니다. ChatGPT 구독과는 별개로, API 크레딧을 충전해야 쓸 수 있습니다.

AI에게 물어보기 — 효과자막 제안

  1. 요청문 복사를 누릅니다.
  2. ChatGPT를 열어 새 대화에 붙여넣고 보냅니다. ChatGPT 열기
  3. ChatGPT가 준 답 전체를 복사해 아래 칸에 붙여넣고 답 적용을 누릅니다.
복사 버튼이 안 될 때: 요청문을 직접 선택해 복사하기

4만들기 효과자막과 효과음이 들어간 새 프로젝트 파일을 받습니다.
